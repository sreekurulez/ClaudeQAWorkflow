# US-002 — Search and clear the item list

**Story ID:** US-002
**Route scope:** `/items`

---

## User story

> As a store manager,
> I want to search my item list and easily get back to the full list,
> so that I can find one item quickly without losing my place.

---

## Acceptance criteria

### AC-1 — Search narrows the list

**Given** I am logged in and on `/items` with the default seeded items,
**When** I type a term matching exactly one item into the search field,
**Then** only the matching item remains in the list.

- UI elements: `data-testid="search-input"`, `data-testid="item-list"`
- Endpoint: `GET /api/items?q=<term>` → 200

### AC-2 — Clearing the search restores the full list

**Given** I have an active search term narrowing the list,
**When** I clear the search field back to empty,
**Then** every seeded item is shown again.

- UI elements: `data-testid="search-input"`, `data-testid="item-list"`

### AC-3 — A search matching nothing shows an empty list, not an error

**Given** I am on `/items`,
**When** I search for a term that matches no item,
**Then** the item list renders with no item rows, and no error is shown.

- UI elements: `data-testid="search-input"`, `data-testid="item-list"`
